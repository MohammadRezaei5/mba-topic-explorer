# کاوشگر موضوعات MBA

این پروژه یک صفحه ساده برای **مرور، جستجو و مشاهده موضوعات پژوهشی حوزه مدیریت کسب‌وکار (MBA)** است. هدف آن این است که دانشجویان بتوانند مجموعه‌ای از موضوعات پایان‌نامه و پژوهش را به‌صورت مرتب مشاهده کنند، در بین موضوعات جستجو کنند و در صورت نیاز عنوان موردنظر خود را به‌راحتی کپی کنند. موضوعات از یک فهرست جداگانه دریافت می‌شوند و نمایش آن‌ها به‌صورت صفحه‌بندی‌شده انجام می‌شود تا پیدا کردن و بررسی موضوعات ساده‌تر باشد.
